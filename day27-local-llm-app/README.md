# День 27. Локальный редактор текста

Веб-приложение отправляет произвольный пользовательский текст в OpenAI-совместимый локальный API. Три режима: сократить, переписать понятно, выделить задачи. Результат можно уточнить с историей, скопировать или скачать в TXT.

**Видео-демо:** [day27-demo.mp4 на Яндекс.Диске](https://yadi.sk/i/rWC60O8DaPRAjQ) — 1:43, 1920×1080, H.264, 25 fps. Реальные кадры браузера: сокращение объявления, выделение задач, уточнение, копирование и подтверждение CPU по процессу/API/журналу. Монтаж с пояснениями, без озвучки; ожидание между кадрами сокращено и это подписано в ролике. Локальная копия: `ChallengeVideos/day27-demo.mp4`, вне Git. Размер опубликованного файла совпал с локальным: 2 159 328 байт.

**Статус:** выполнен реальный прогон на CPU с Qwen3-1.7B-Q4_K_M через llama-server (2026-10-06), включая ответы в браузере и видео. Strata не менялась. Полная автономность при отключённой внешней сети отдельно не проверялась.

## Qwen3 на CPU

Запустите в двух терминалах `run-cpu-model.bat` и `run-cpu-app.bat`. Первый использует пути к llama-server и GGUF, предоставленные пользователем; можно переопределить `LLAMA_SERVER` и `MODEL`. Второй открывает приложение на http://127.0.0.1:8792, API модели — http://127.0.0.1:8084/v1. Если эти процессы уже работают, повторно запускать их не нужно.

CPU обеспечивается параметрами `--device none --gpu-layers 0 --no-kv-offload --no-op-offload`. Настройки: 8 потоков, один слот, 8192 токена контекста, thinking отключён через `--reasoning off`, максимум генерации 1024 токена. Поддержка флагов проверена по `--help` установленного executable, сервер загрузил указанную GGUF и ответил на `/health` и `/v1/models`. CUDA-сборка executable используется с явно отключённым offload; это не GPU-прогон.

Два полных прогона сохранены: [исходный](artifacts/cpu-initial.json), [после уточнения инструкций](artifacts/cpu-refined.json). Все восемь запросов получили непустой ответ и `finish_reason=stop`. В первом прогоне: 2,7–5,8 с, около 14–16 токенов/с генерации по журналу llama-server. Во втором: сокращение 5,9 с, понятная формулировка 8,2 с, задачи 2,4 с, уточнение 1,7 с. Это разные объёмы ответа, не сравнение скорости моделей.

Качество проверено вручную на этих примерах: исходный прогон пропустил заполнение обязательных полей, ошибочно включил обсуждение в задачи и исказил сроки при уточнении. После усиления инструкций задачи и уточнение сохранили исполнителей/сроки и исключили обсуждение; режим понятной формулировки всё ещё дублирует проверку почты и нарушает порядок первых шагов. Поэтому успешный HTTP не означает правильный ответ. Модель пригодна для демонстрации интеграции, результаты требуют проверки. В браузере отдельный реальный запрос выделил две задачи за 1,7 с.

Повторный прогон (делает реальные запросы):

```powershell
$env:DAY27_APP_URL = 'http://127.0.0.1:8792'
node day27-local-llm-app/evaluate.mjs
```

## Запуск

Node.js 22+, дополнительных пакетов нет. Strata запускается отдельно пользователем. Укажите актуальные URL и id из её настроек; значения ниже соответствуют сохранённому прогону дня 26 и требуют сверки.

```powershell
$env:LOCAL_LLM_URL = 'http://127.0.0.1:8083/v1'
$env:LOCAL_LLM_MODEL = 'qwen3.8-flash-next-iq3_s'
node day27-local-llm-app/server.mjs
```

Откройте http://127.0.0.1:8789. Запуск приложения и чтение конфигурации не обращаются к Strata; запрос отправляется только по кнопке обработки или уточнения.

Настройки: `DAY27_WEB_PORT` (8789), `LOCAL_LLM_TIMEOUT_MS` (180000), при необходимости `LOCAL_LLM_API_KEY` (только на сервере). Ключ не сохраняйте в Git. Приложение не отключает авторизацию API.

## Использование

1. Вставьте текст и выберите режим.
2. Нажмите «Обработать текст», дождитесь ответа.
3. Уточните результат: «Сделай короче, сохрани все сроки».
4. Скопируйте ответ или скачайте TXT. «Новая работа» очищает исходник, результат и историю.

Уточнения относятся к исходнику и режиму последней успешной обработки. Если после неё изменить исходник или режим, нажмите «Обработать текст», чтобы начать новый диалог. Ошибка/отмена сохраняет последний успешный результат. Отмена прекращает ожидание и HTTP-запрос приложения; фактическая остановка инференса зависит от Strata.

История только в памяти вкладки, без постоянного хранения. Исходник — до 12 000 символов, уточнение — до 2 000, максимум пять успешных уточнений после первого ответа, суммарный передаваемый текст — до 40 000 символов. Это лимиты приложения в символах, не размер контекста модели в токенах. При исчерпании начните новую обработку. Один запрос генерации одновременно на сервер; другие получают сообщение о занятости. Ответ `finish_reason=length` отмечается как обрезанный.

## Полностью локальный путь

Браузер → Node на 127.0.0.1 → literal loopback HTTP API → браузер. Нет облачных провайдеров/fallback, embeddings, CDN, аналитики или загрузок моделей. Редиректы API запрещены. System-инструкции задаёт сервер; история допускает только чередующиеся user/assistant. Ответ показывается как текст, не исполняется как HTML или код. Проверяются Host/Origin и размер тела; статика отдаётся по фиксированному списку.

Loopback-адрес подтверждает маршрут клиента, но сам по себе не доказывает устройство сервера инференса. Реальную локальность подтвердить Strata Monitor/журналом и работой без внешней сети. Приложение рассчитано на личное использование на одном компьютере, не на публичный хостинг. Инструкции модели не гарантируют защиту от инструкций внутри исходного текста; приложения инструментов и исполнения кода здесь нет.

## Проверки

```powershell
node --test day27-local-llm-app/app.test.mjs
node --check day27-local-llm-app/server.mjs
node --check day27-local-llm-app/web/app.js
```

Тесты: контекст уточнений, валидация, конфигурация, сериализация HTTP, авторизация, метаданные, HTTP/JSON/пустые ответы, редиректы, таймаут, отмена, origin, отсутствие запроса при чтении конфигурации, занятость и восстановление после ошибки.

Проверено при разработке: 7 тестов прошли, в том числе после изменения инструкций и добавления демо-режима. В браузере с явно обозначенным тестовым API проверены обработка, уточнение, копирование, текстовый вывод `<script>` и сохранение результата при HTTP 503. Автоматическая проверка скачивания TXT завершилась таймаутом браузерного инструмента; реальное скачивание и содержимое файла пока не подтверждены. Видео полностью декодировано ffmpeg без ошибок; вручную просмотрены извлечённые кадры ответа, задач, уточнения, CPU и финала.
