# Видео и воспроизведение

1. Открытый рабочий интерфейс; нажимаем «Запустить ревью».
2. Сервер вызывает тот же run(), что CLI и GitHub Action: Git → RAG → Gemini.
3. В браузере появляется настоящий diff pricing.py и новая версия файла.
4. Нажимаем «RAG-источники», читаем docs/architecture.md, pricing.py, checkout.py.
5. После настоящего ответа модели открываем «Результат ревью» и прокручиваем его.

capture-demo.mjs управляет настоящим Chrome через CDP и непрерывно сохраняет кадры.
Запуск кнопкой делает новый запрос модели, не воспроизводит сохранённый ответ.
record_video.py кодирует кадры по исходным timestamps, без ускорения ожидания.
Это локальная демонстрация, не запись GitHub Actions. Исходные кадры video-frames/
исключены из Git; состояние и последовательность кадров — evidence/live-browser.json,
параметры видео — evidence/video.json.
Выход ChallengeVideos/day32-demo.mp4 исключён из Git общим *.mp4.
