# День 18: работающая капсула h3llo cloud

Капсула `strong-platform-5478` (Ubuntu 24.04, CAPSULE-SMALL, 1 vCPU / 2 ГБ RAM) запущена. В панели указан публичный IP `176.53.175.196`; SSH-пользователь — `user`, ключ — `ai-advent-vps`.

## Подключение с Windows

Откройте PowerShell и выполните:

```powershell
ssh -i "$env:USERPROFILE\.ssh\ai_advent_vps" user@176.53.175.196
```

Приглашение командной строки на сервере начинается с `user@vm-...`. Команда `exit` возвращает на ваш компьютер. Приватный ключ остаётся в `C:\Users\ArnyPC\.ssh`; его содержимое не передаётся провайдеру. В панели находится только публичный ключ.

Чтобы прочитать последнюю сводку прямо из PowerShell на своём компьютере:

```powershell
ssh -i "$env:USERPROFILE\.ssh\ai_advent_vps" user@176.53.175.196 'cd /home/user/ai-advent/day18-rss-scheduler && DAY18_DB_PATH=/home/user/ai-advent/data/feed.sqlite3 .venv/bin/python show_digest.py'
```

## Что установлено на капсуле

- Код: `/home/user/ai-advent/day18-rss-scheduler`.
- Python-окружение: `.venv` внутри этого каталога.
- SQLite: `/home/user/ai-advent/data/feed.sqlite3`.
- `day18-collect.timer`: сбор Habr RSS каждые два часа.
- `day18-digest.timer`: сводка ежедневно в 09:00 по Екатеринбургу (04:00 UTC).
- `DAY18_DIGEST_MODE=plain`: сводка создаётся без моделей и API-ключей.

После первого запуска получено 40 RSS-публикаций; сводка из 10 материалов сохранена в SQLite. Локальная панель с кнопками управления не открыта в интернет; рабочие задачи запускает `systemd`.

Для проверки через браузер запущена **отдельная публичная страница только для чтения**: [http://176.53.175.196:8080/](http://176.53.175.196:8080/). [Видео проверки доступно там же](http://176.53.175.196:8080/demo.mp4). На странице нет кнопок, меняющих базу; доступ к ней не нужен для работы таймеров. Служба: `day18-public.service`.

Проверка из SSH-сеанса:

```bash
systemctl list-timers day18-collect.timer day18-digest.timer
systemctl status day18-collect.timer day18-digest.timer
journalctl -u day18-collect.service -u day18-digest.service -n 30 --no-pager
```

Ручной сбор или сводка:

```bash
sudo systemctl start day18-collect.service
sudo systemctl start day18-digest.service
```

При отсутствии новых публикаций сводка пропускается с успешным завершением задачи. MCP-инструмент `get_habr_digest` читает последнюю сохранённую сводку из той же SQLite. Для подключения удалённого MCP по SSH понадобится отдельная настройка клиента.

## Диск и резервная копия

В тарифе указано 30 ГБ SSD, но Ubuntu сейчас видит устройство `/dev/vda` размером 15 ГБ и корневой раздел около 14 ГБ. Это следует уточнить у поддержки h3llo cloud. Капсула имеет меньшую избыточность хранения, чем обычная ВМ; после исправления размера диска стоит настроить копию SQLite вне капсулы.

## Локальное видео

Короткие интервалы 6/45 секунд используются только в локальном видеодемо. На капсуле действуют интервалы 2 часа/1 день; её планировщик не зависит от локального компьютера.
