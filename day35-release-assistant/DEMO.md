# Живая демонстрация дня 35

Задача: подготовить реальные материалы обновления DnsHostsGenerator.
Диапазон: v1.4.0 → v1.4.1, восемь коммитов, 30 изменённых файлов.

1. Показать название проекта и проблему ручной подготовки релиза.
2. Выбрать версии. В кадре видно выбранного провайдера/модель и сообщение
   об отправке разрешённых исходников. Ключи в кадр не попадают.
3. Нажать «Подготовить материалы». Записывается НОВЫЙ запрос живой модели.
4. Показать события: Git → статусы проверок → AI → валидация.
5. Показать результаты JVM-тестов, Android debug и Windows desktop-сборки.
   Все три проверки пройдены на точном SHA; требуется просмотр материалов.
6. Показать пользовательские изменения, открыть реальный источник S из ответа.
7. Показать ручные проверки с ожидаемыми результатами.
8. Показать описание обновления и файлы отчёта. Скопировать черновик.
