# DnsHostsGenerator

Kotlin Multiplatform приложение для генерации `hosts`-файлов из групп доменов через выбранные DNS-провайдеры и импорта доменов в NextDNS Rewrites (Android).

## Какую боль решает

Когда сервисы частично недоступны, часто приходится вручную собирать домены, проверять их через рабочий DNS, удалять дубли и складывать результат в `hosts`. Это долго, легко ошибиться и неудобно поддерживать.

DnsHostsGenerator делает этот сценарий быстрым:

- хранит домены по группам: OpenAI, Gemini, GitHub, Spotify и т.д.;
- позволяет включать/выключать группы галочками, в том числе массово включать или выключать все группы;
- даёт добавлять, редактировать и удалять свои группы и домены;
- валидирует домены при вводе;
- генерирует готовый `hosts`-файл через рекомендуемый DNS;
- может сравнить результат через несколько DNS-пресетов;
- показывает прогресс генерации и позволяет остановить её кнопкой **Стоп**;
- показывает статистику по активным hosts, forwarded, unresolved и duplicate, подсвечивает служебные строки результата и предупреждает о вероятном перехвате DNS;
- поддерживает поиск по группам и доменам, светлую и тёмную тему;
- на Android умеет импортировать домены во временный профиль NextDNS Rewrites;
- показывает DNS-сервер созданного NextDNS профиля и позволяет скопировать его в буфер обмена.

## Основные сценарии

### Генерация hosts

1. Открыть приложение.
2. Включить нужные группы доменов.
3. Оставить рекомендуемый DNS или выбрать DNS-пресеты для сравнения.
4. Нажать **Сгенерировать hosts**.
5. Скопировать или сохранить результат.

### Как работает DNS-резолвинг

Запросы к выбранному DNS-провайдеру выполняются по **DNS-over-TLS (DoT, порт 853)** с проверкой TLS-сертификата. Это обходит прозрачный перехват DNS-трафика (VPN-антиблокировщики, DNS-прокси операторов), при котором primary и проверочный резолверы возвращают одинаковые IP и все домены ошибочно помечаются `#forwarded`.

- если DoT недоступен — автоматический fallback на обычный DNS (UDP/TCP 53);
- проверочный DNS `8.8.8.8` запрашивается через DoT-эндпоинт `dns.google:853`;
- для провайдеров с просроченными TLS-сертификатами (`dns.mafioznik.xyz`, `free.shecan.ir`) проверка сертификата отключается (`allowInvalidTls`);
- домены, у которых primary и проверочный DNS возвращают одинаковые IP, помечаются `#forwarded` — это нормальное поведение: прокси-DNS не проксирует такие домены, и запись в hosts не требуется;
- если почти все домены помечены `#forwarded`, приложение предупреждает о возможном перехвате DNS.
- домены резолвятся параллельно (до 16 одновременно), каждый уникальный домен запрашивается один раз; порядок строк в итоговом hosts сохраняется.

### Импорт в NextDNS (Android)

Импорт в NextDNS доступен только на Android — он нужен, чтобы получить адрес для системного «Частного DNS». На desktop его нет.

Блок **Частный DNS через NextDNS** находится на главном экране под результатом, отдельный экран не нужен.

1. Сгенерировать hosts (или просто включить нужные группы).
2. Нажать **Импортировать в NextDNS** — текст подставляется, парсится и импортируется одной кнопкой. Если hosts уже сгенерирован, импортируются его записи; иначе — домены включённых групп с IP из поля.
3. Следить за подробным прогрессом прямо в блоке: фаза, всплески, успешные/ошибки/пропущенные/повторы, прошло/осталось, скорость, текущий домен. Импорт можно остановить кнопкой **Стоп**.
4. Нажать **Копировать** и вставить адрес в «Настройки → Сеть и интернет → Частный DNS».

Поддерживается ввод:

```text
example.com
another-domain.org
```

и hosts-формат:

```text
1.2.3.4 example.com
2001:4860:4860::8888 ipv6-example.org
```

Для обычного списка доменов используется IP из поля **IP для доменов**. Для hosts-строк IP берётся из самой строки.

## Данные доменов

Приложение использует Room KMP database.

При первом запуске база заполняется seed-данными из:

```text
shared/src/commonMain/composeResources/files/seed_data.sql
```

В базе есть:

- группы доменов;
- домены внутри групп;
- флаг `isEnabled` для группы;
- пользовательские домены с `isCustom`.

Текстовая вкладка оставлена для просмотра итогового списка в старом формате:

```text
# --- Group name ---
domain1.com
domain2.com
```

+object AndroidArchivePicker {
+    /** Показать системный диалог выбора файла (регистрируется в MainActivity). */
+    @Volatile
+    var openFileDialog: (() -> Unit)? = null
+
+    /** Доставка выбранного uri из MainActivity в ожидающий вызов [pickArchive]. */
+    @Volatile
+    var deliverPickedUri: ((Uri?) -> Unit)? = null
+
+    @Volatile
+    var contentResolver: ContentResolver? = null
+}
+
+actual suspend fun pickArchive(): PickedArchive {
+    val open = AndroidArchivePicker.openFileDialog
+    if (open == null) {
+        return PickedArchive(message = "Выбор файла недоступен: диалог не зарегистрирован")
+    }
+    val uri = suspendCancellableCoroutine { continuation ->
+        AndroidArchivePicker.deliverPickedUri = { picked ->
+            AndroidArchivePicker.deliverPickedUri = null
+            if (continuation.isActive) continuation.resume(picked)
+        }
+        open()
+    }
+    if (uri == null) return PickedArchive(message = "Файл не выбран")
+
+    val resolver = AndroidArchivePicker.contentResolver
+        ?: return PickedArchive(message = "Android context is not initialized")
+
+    return withContext(Dispatchers.IO) {
+        runCatching {
+            resolver.openInputStream(uri)?.use { stream -> stream.readBytes() }
+        }.map { bytes ->
+            if (bytes == null) {
+                PickedArchive(message = "Не удалось открыть файл")
+            } else {
+                val entries = unzipTextEntries(bytes)
+                if (entries.isEmpty()) {
+                    PickedArchive(message = "В архиве нет текстовых файлов")
+                } else {
+                    PickedArchive(entries = entries)
+                }
+            }
+        }.getOrElse { error ->
+            AppLogger.e("Archive read failed: $uri", error)
+            PickedArchive(message = "Не удалось прочитать архив: ${error.message}")
+        }
+    }

+actual fun zipTextEntries(entries: List<ZipTextEntry>): ByteArray {
+    val buffer = ByteArrayOutputStream()
+    ZipOutputStream(buffer).use { zip ->
+        entries.forEach { entry ->
+            zip.putNextEntry(ZipEntry(entry.name))
+            zip.write(entry.content.toByteArray(Charsets.UTF_8))
+            zip.closeEntry()
+        }
+    }
+    return buffer.toByteArray()
+}

+actual fun unzipTextEntries(
+    bytes: ByteArray,
+    maxEntries: Int,
+    maxTotalBytes: Int,
+): List<ZipTextEntry> {
+    val result = mutableListOf<ZipTextEntry>()
+    var totalBytes = 0
+    ZipInputStream(ByteArrayInputStream(bytes)).use { zip ->
+        var entry: ZipEntry? = zip.nextEntry
+        while (entry != null && result.size < maxEntries) {
+            if (!entry.isDirectory && isTextEntryName(entry.name)) {
+                val data = zip.readBytes()
+                if (totalBytes + data.size <= maxTotalBytes) {
+                    totalBytes += data.size
+                    result += ZipTextEntry(entry.name, data.toString(Charsets.UTF_8))
+                }
+            }
+            zip.closeEntry()
+            entry = zip.nextEntry
+        }
+    }

+actual fun zipTextEntries(entries: List<ZipTextEntry>): ByteArray {
+    val buffer = ByteArrayOutputStream()
+    ZipOutputStream(buffer).use { zip ->
+        entries.forEach { entry ->
+            zip.putNextEntry(ZipEntry(entry.name))
+            zip.write(entry.content.toByteArray(Charsets.UTF_8))
+            zip.closeEntry()
+        }
+    }
+    return buffer.toByteArray()
+}
+
+actual fun unzipTextEntries(
+    bytes: ByteArray,
+    maxEntries: Int,
+    maxTotalBytes: Int,
+): List<ZipTextEntry> {
+    val result = mutableListOf<ZipTextEntry>()
+    var totalBytes = 0
+    ZipInputStream(ByteArrayInputStream(bytes)).use { zip ->
+        var entry: ZipEntry? = zip.nextEntry
+        while (entry != null && result.size < maxEntries) {
+            if (!entry.isDirectory && isTextEntryName(entry.name)) {
+                val data = zip.readBytes()
+                if (totalBytes + data.size <= maxTotalBytes) {
+                    totalBytes += data.size
+                    result += ZipTextEntry(entry.name, data.toString(Charsets.UTF_8))
+                }
+            }
+            zip.closeEntry()
+            entry = zip.nextEntry
+        }
+    }
+    return result
