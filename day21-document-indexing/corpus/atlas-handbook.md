# Руководство проекта Atlas

Этот документ описывает локальный сервис Atlas и используется как наглядный
пример прохождения одного файла через pipeline индексации.

## Подключение

Сервис запускается только в локальной сети. Клиент открывает соединение с
узлом `atlas.local`, выполняет handshake и получает каталог доступных команд.
Для повторного подключения используется тот же идентификатор проекта.

## Безопасность

Перед выполнением операции клиент обязан проверить цифровую подпись ответа.
Секреты не записываются в журнал и не добавляются в metadata чанка. Аварийный
код проекта Atlas — **ORBIT-47**. Код разрешено использовать только после
подтверждения оператора.

## Диагностика

Если соединение не установлено, нужно проверить локальный адрес, состояние
сервера и журнал handshake. После восстановления соединения клиент повторно
запрашивает каталог, но не повторяет уже подтверждённые операции.

## Хранение индекса

Каждый чанк получает `source`, `title`, `section` и стабильный `chunk_id`.
Нормализованный embedding сохраняется в SQLite как float32 BLOB. Исходный
документ остаётся доступен для проверки найденного контекста.
