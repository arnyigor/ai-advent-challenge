# Проверки дня 33

- `verification.json`: 11 групп проверок. MCP настоящий, отдельный subprocess;
  для ошибок провайдера и изоляции истории используется явно тестовая генерация.
- `live-answers.json`: одинаковый вопрос, два разных тикета, настоящие ответы
  Wormsoft / qwen3.8-27b с публичной VPS, найденные статьи и MCP-трасса.
- `live-extra.json`: отсутствие email-напоминаний, вопрос вне предметной области,
  отказ обещать действия по команде prompt injection. Полные ответы сохранены.
- `live-browser.json`: реальная непрерывная запись браузера, три LLM-ответа,
  проверка сохранения покупки/истории и мобильной ширины без переполнения.
  Временные JPEG-кадры и профиль Chrome исключены из Git и архива. Автоматическая
  проверка среды заблокировала удаление после сборки: они остались только локально.
- `deployment.json`: HTTPS, redirect, служба/автозапуск, перезапуск с сохранением
  покупки и чата в той же cookie, изоляция экспорта и воспроизведение MP4 по Range.
  День 18 остаётся active и отвечает HTTP 200.
- `video.json`: ffprobe и размер/длительность финального MP4.
- PNG: исходные скриншоты браузера, включая телефон 390 px.

Тесты не утверждают безошибочность LLM на любых вопросах. Автоматически проверяются
форма ответа и принадлежность ID цитат найденному набору; содержание реальных
ответов в этих сценариях дополнительно прочитано и проверено по FAQ.
