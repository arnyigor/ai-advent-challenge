# Демо дня 33

Непрерывная запись реального браузера на публичном HTTPS сервисе.
Скрипт не подставляет готовые ответы и не ускоряет ожидание модели.

1. Пустой кабинет «Мои гарантии» и создание покупки «Кофемашина».
2. Запись сохранена: дата окончания и оставшиеся дни.
3. «Поддержка»: список обращений, выбранный SK-1042, пользователь и события.
4. «Почему не работает авторизация?» → реальный ответ модели, LINK_EXPIRED.
5. Открытие источника: полный раздел FAQ и проверка срока ссылки.
6. Тикет SK-1043, тот же вопрос → SESSION_MISMATCH и другие шаги.
7. Раскрытие MCP-трассы: сервер srokok-crm, каталог инструментов, tools/call.
8. Уточнение «А cookie удалять?» → ответ в контексте предыдущего вопроса.

После записи автоматическая QA проверяет сохранение покупки/истории при обновлении
и мобильную ширину 390 px. Скриншоты и фактические ответы — в evidence/.

```powershell
$env:DAY33_DEMO_URL = 'https://srokok.176.53.175.196.sslip.io/'
node day33-support-assistant/capture-demo.mjs
.venv/Scripts/python.exe day33-support-assistant/record_video.py
```

Требуются Chrome, Node.js с WebSocket, ffmpeg и ffprobe. CHROME_PATH можно задать
явно. Видео сохраняется в ChallengeVideos/day33-demo.mp4 и исключено из Git.
