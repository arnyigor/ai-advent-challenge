# День 24. Ответ, источники и цитаты

**Видео-демо:** [day24-demo.mp4 на Яндекс.Диске](https://yadi.sk/i/GvgI9-DQ7io1Qw) — 65 секунд: пошаговая подсветка ответа, списка источников и цитат, проверки всех 10 вопросов и «не знаю» при релевантности ниже порога.

Модель возвращает **answer**, **sources** и **quotes** в своём JSON.
Сервер проверяет структуру, метаданные source / section / chunk_id, дословность
цитат и смысловую поддержку каждого утверждения. Ответ без доказательств не показывается.

В интерфейсе три отдельные колонки. Слева — утверждения У1/У2, в центре —
источники И1/И2, справа — цитаты Ц1/Ц2. Нажмите утверждение: связанные источник
и цитата получат жёлтую подсветку. «Показать по шагам» ведёт через ответ,
источники, цитаты и проверку; сверху всегда объясняется, куда смотреть.

## Соответствие заданию

Те же **10 вопросов** Дней 22/23 проверены повторно реальными вызовами DeepSeek.

| Проверка | Результат |
|---|---:|
| Источники присутствуют | 10/10 |
| Цитаты присутствуют | 10/10 |
| Смысл ответа подтверждён цитатами | 10/10 по оценке LLM |
| Цитаты дословно входят в чанки | 10/10 |
| source / section / chunk_id совпадают с индексом | 10/10 |
| Сама модель вернула обязательные поля | 10/10 |
| Вопросы вне корпуса: корректный отказ + уточнение | 2/2 |

Полные ответы, исходные JSON модели, цитаты, метаданные и кандидаты —
`results/grounding.json`. Проверка по пунктам задания — `results/REQUIREMENTS_CHECK.md`.
Дополнительный просмотр каждого ответа и его цитат — `results/review.md`.
Отчёт не приравнивает качество цитирования к полноте ответа.

Пример слабого контекста: вопрос о текущей цене акций дал **max cosine 0.813 <
threshold 0.830**. Генерация ответа пропущена (`prompt_chars=0`), ассистент говорит
«Не знаю» и просит уточнить. Поля sources и quotes у отказа пустые: доказательства
не выдумываются. На 10 контрольных вопросах все эти поля непустые.

## Pipeline и связь с Днём 23

Сохранены query rewrite, cosine threshold 0.83, rerank (75% cosine + 25% lexical
overlap), top-4, нормализация идентификаторов и полная трассировка кандидатов Дня 23.
Его код подключается отдельным именованным модулем и не меняется.

Поиск дополнен FTS5: объединяются vector top-8 и lexical top-8 — максимум
16 уникальных кандидатов. Для каждого lexical-кандидата рассчитывается настоящий
cosine на той же embedding-модели. Ни один кандидат не обходит порог. Это позволяет
найти точные операции в коде, например INSERT OR IGNORE в feed_store.py.

Индекс — `day21-document-indexing/data/indexes/structure.sqlite3`, вопросы —
`day22-first-rag-request/control_questions.json`. Папка Дня 24 использует соседние
дни 21/23 и общий tools/llm, поэтому запускается внутри этого репозитория.

## Контракт модели

Модель возвращает JSON:

- `status`: answered или unknown;
- `answer`: текст, состоящий только из подтверждённых claims;
- `sources`: source, section, chunk_id каждого использованного чанка;
- `quotes`: дословная quote, chunk_id и номер утверждения claim;
- `claims`: атомарные утверждения с evidence для проверяемой связи.

Код требует все поля, проверяет совпадение answer с claims, сверяет источники
с индексом, а quotes — с evidence и исходными текстами чанков.
Отдельный вызов модели проверяет смысл каждой пары утверждение/цитата.
При ошибке разрешена одна попытка исправления, затем — «не знаю» и уточнение.
Если релевантность всех кандидатов ниже порога, генерация ответа не запускается.

API также возвращает `model_output`, `semantic_check`, `validation_errors`,
`retrieved_chunks`, `candidates`, `retrieval`, настройки и причину решения.
Исходный JSON можно открыть в UI: «Что именно вернула модель».

Смысловой verdict — оценка той же модели в отдельном вызове, а не гарантия истинности.
Дословность, метаданные и обязательные поля проверяются программно.

## Запуск

Из корня репозитория:

```powershell
.\.venv\Scripts\python.exe -m pip install -r day24-citations-grounding\requirements.txt
.\.venv\Scripts\python.exe day24-citations-grounding\rag_agent.py
.\.venv\Scripts\python.exe day24-citations-grounding\web_server.py
.\.venv\Scripts\python.exe day24-citations-grounding\evaluate.py
```

Сервер печатает URL; порт задаётся DAY24_WEB_PORT. Модель по умолчанию —
`deepseek:deepseek-v4-flash`, используются настройки общего LLM client.
Настройки: DAY24_MODEL, DAY24_TOP_K_BEFORE, DAY24_TOP_K_AFTER,
DAY24_SIMILARITY_THRESHOLD; для агента CLI --model, --threshold, --top-k-before,
--top-k-after, --index. evaluate.py принимает --model.
Необходим уже построенный индекс Дня 21 и настроенный провайдер.
