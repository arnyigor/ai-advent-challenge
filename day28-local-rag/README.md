## Запуск

Python из существующей .venv; зависимости: `requirements.txt`. Нужны существующий индекс `day21-document-indexing/data/indexes/structure.sqlite3` и локальный кеш `intfloat/multilingual-e5-small`. Embeddings загружаются только с local_files_only, без скачивания. Не заменяйте их другой моделью с той же размерностью.

```powershell
# Без моделей: прочитать фактические метаданные индекса
.\.venv\Scripts\python.exe day28-local-rag\rag.py --inspect

# Подтверждённая 2026-10-07 конфигурация Strata
$env:LOCAL_LLM_URL = 'http://127.0.0.1:8083/v1'
$env:LOCAL_LLM_MODEL = 'qwen3.8-flash-next-iq3_s'
$env:LOCAL_LLM_MAX_TOKENS = '4096'
.\.venv\Scripts\python.exe day28-local-rag\server.py
```

Открыть http://127.0.0.1:8793. Альтернатива — `run-app.bat`, который запускает только приложение, не сервер модели. При старте и GET config модель не вызывается. Кнопка «Только поиск» загружает E5 на CPU; «Найти и ответить» дополнительно вызывает LLM.

```powershell
# Эти команды используют реальные модели
.\.venv\Scripts\python.exe day28-local-rag\rag.py 'Какой аварийный код у проекта Atlas?' --retrieve-only
.\.venv\Scripts\python.exe day28-local-rag\rag.py 'Какой аварийный код у проекта Atlas?'
.\.venv\Scripts\python.exe day28-local-rag\evaluate.py --run --repeats 3
# Опционально: отправляет найденный контекст облачному провайдеру
.\.venv\Scripts\python.exe day28-local-rag\evaluate.py --run --cloud-model deepseek:deepseek-v4-flash
# Сложные вопросы, включая ложную предпосылку и отсутствие фактов
.\.venv\Scripts\python.exe day28-local-rag\evaluate.py --run --cases day28-local-rag\complex_queries.json --cloud-model deepseek:deepseek-v4-flash --output day28-local-rag\results\complex.json
```

Отчёт: results/comparison.json, вне Git. 13 вопросов × 3 повтора на провайдера; одинаковый prompt, время retrieval/generation отдельно, median/p95, успехи, обрезанные ответы, повторяемость текста. Качество заполняется вручную в manual_quality (0/1/2) и notes после сверки с фрагментами. Время первого поиска включает загрузку E5. Сохранённые ответы облачной модели предыдущих дней не считаются честным сравнением: контекст и параметры отличались.

## Ограничения

Один запрос генерации на вопрос; нет памяти чата и смыслового валидатора дня 24. В финальном поиске объединяются 32 vector + 32 FTS5 кандидата, rank = 75% cosine + 25% совпадение терминов, выбираются top-6. PLAN.md исключается, если пользователь явно не спрашивает о плане. Для дублей есть локальное расширение поисковых терминов (dedup, primary key, insert ignore). Косинусный порог не применяется: даже высокий score не гарантирует ответ. Проверка номеров ссылок не доказывает факты.

Бюджет ответа 4096 токенов (`LOCAL_LLM_MAX_TOKENS`, диапазон 128–8192), контекст до 18 000 символов. Strata сообщила окно 204 800 токенов; CPU-вариант дня 27 с окном 8192 отдельно здесь не проверялся. Существующая модель и её настройки не менялись. Внешние ресурсы UI и cloud fallback отсутствуют; облако используется только явно в сравнении. HTTP/API ошибки не подменяются ответами. Статистика p95/median считается по успешным вызовам, три повтора используют кеш контекста, поэтому это не независимые холодные запуски.

## Базовый реальный прогон

Vector-only top-4 и бюджет 700 токенов, 13 вопросов × 3 повтора. Strata: 36/39 непустых ответов, медиана 9,59 с, p95 23,14 с. DeepSeek: 39/39, медиана 1,40 с, p95 1,79 с. На вопросе дедупликации RSS поиск не нашёл код: Strata трижды вернула пустой content, а DeepSeek отказался. Монитор Strata подтвердил три `Max tokens` на 700 токенах (28,2 / 27,0 / 25,5 с). Эти ошибки сохранены; лимит и поиск исправлены для следующего прогона.

Оценки агентом после сверки всех сохранённых ответов с исходниками: Strata 1,641/2, DeepSeek 1,667/2. Это условная оценка всей системы, включая недостаточный поиск и отсутствие ответа; не независимая слепая экспертиза моделей. Неполные ответы про историю называли только self.store, без SQLite; один локальный ответ смешал локальный scheduler и процессы VPS, другой внёс неверный порядок verify/summarize. Отказ на staged diff корректен: он отсутствует в реализованном Git-инструменте дня 17.

## Сложные запросы и итоговая конфигурация

Составные вопросы про Atlas, дедупликацию RSS, ограничения MCP, Git; исправление двух ложных предпосылок и отказ выдумывать выручку/заказчика. Гибридный top-6, бюджет 2000, 6 вопросов × 3 повтора × 2 провайдера.

| Прогон | Провайдер | Непустые ответы | Обрезаны | Медиана / p95 | Качество, 0–2 |
|---|---|---|---|---|---|
| Сложные, 2000 | Strata | 18/18 | 1 | 22,27 / 67,42 с | 1,889 |
| Сложные, 2000 | DeepSeek | 18/18 | 0 | 1,70 / 2,95 с | 1,889 |
| RSS-перепроверка, 4096 | Strata | 3/3 | 0 | 51,56 / 54,82 с | 2,000 |
| RSS-перепроверка, 4096 | DeepSeek | 3/3 | 0 | 2,15 / 2,23 с | 1,333 |

В сложном наборе Strata трижды исправила ORBIT-48 на ORBIT-47 и вернула обязательное подтверждение оператора; трижды отказалась выдумывать выручку. Для MCP ответ объяснил server.tool, проверку истории и исключения guard. В одном повторе неточно названо поле каталога (`route` вместо `name`). Один RSS-ответ обрезался на 2000 токенах; поэтому итоговый бюджет приложения увеличен до 4096. С ним повторены три RSS-запроса на точно том же контексте: все `finish_reason=stop`, факты и ограничения сохранены. У DeepSeek в части RSS-ответов вставка в БД смешана с неподтверждённой внешней отправкой.

Стабильность: успешность HTTP и полнота ответа считаются отдельно. Варьируется формулировка: три RSS-ответа Strata различаются дословно, но в перепроверке сохраняют основные факты. Вывод не распространяется на произвольные вопросы. В трёх сравнительных прогонах сохранено **120 вызовов**: 60 локальных и 60 облачных. Отдельно выполнены проверка локальности и реальные запросы в UI.

В Strata Monitor наблюдались RTX 5070 Ti, 15,6/16 GB VRAM и генерация около 27–32 токенов/с. Задержка HTTP включает prefill, reasoning и ответ. В локальном RSS-прогоне completion_tokens достигает 1205–2000, а облачный клиент отключает thinking по стандартному контракту репозитория. Reasoning-режимы провайдеров не уравнивались; сравнение показывает фактическое поведение этих конфигураций, не изолированную производительность моделей.

## Локальность и доказательства

`verify_local.py` выполняет реальный запрос, запрещая Python socket.connect к любому адресу вне literal loopback. Контрольный внешний адрес блокируется до системного соединения. E5 загрузился из кеша; получен правильный ответ Atlas. Зафиксировано только одно соединение к `127.0.0.1:8083`, внешних попыток приложения нет. Ограничение действует на процесс Python RAG; сеть ОС и отдельного процесса Strata не отключалась. GPU-инференс отдельно наблюдался в Strata Monitor. Полный тест с отключённой сетью компьютера не выполнялся.

Сохранённые реальные ответы/контекст и оценки находятся в `evidence/`. Исходные неудачные результаты сохранены, не заменены повторным прогоном. `audit_quality.py` проверяет соответствие отзывов SHA-256 ответа и контекста, не вызывает модель. Локальный HTML-отчёт — `results/report.html`, доступен на http://127.0.0.1:8793/report; чтение отчёта не выполняет inference.

```powershell
# Повторная проверка уже сохранённых оценок, без модели
.\.venv\Scripts\python.exe day28-local-rag\audit_quality.py day28-local-rag\evidence\complex.json day28-local-rag\evidence\complex-reviews.json
# Реальная проверка локальных соединений
.\.venv\Scripts\python.exe day28-local-rag\verify_local.py
# Реальная перепроверка длинного ответа с текущим бюджетом
.\.venv\Scripts\python.exe day28-local-rag\evaluate.py --run --cases day28-local-rag\long_queries.json --cloud-model deepseek:deepseek-v4-flash --output day28-local-rag\results\regression.json
```

Честное сравнение провайдеров выполняется внутри одного прогона. Базовый и сложный наборы имеют разные вопросы, top-k и бюджет; их скорости и оценки нельзя выдавать за контролируемое сравнение алгоритмов поиска. В базовом прогоне клиент не сохранял cloud finish_reason; значение truncation для облака неизвестно, а не ноль. Для сложного прогона метаданные сохраняются.
