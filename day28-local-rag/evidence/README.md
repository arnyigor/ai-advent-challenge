# Доказательства реального прогона 2026-10-07

- comparison.json: 13 вопросов недели 6 × 3 повтора, vector-only top-4, бюджет 700; включает ошибки.
- complex.json: 6 сложных вопросов × 3 повтора, гибридный top-6, бюджет 2000; включает обрезанный ответ.
- regression.json: повтор RSS-вопроса × 3, тот же контекст, бюджет 4096.
- *-reviews.json: оценки агентом по исходникам (0–2), SHA-256 точного ответа и prompt. Это субъективная сверка, не независимая слепая экспертиза.
- models.json: ответ Strata /v1/models с loaded и n_ctx=204800.
- strata-monitor.txt: наблюдавшийся DOM монитора с GPU и тремя Max tokens по 700 токенов.
- local-network-check.json: реальный RAG под ограничением socket.connect, только 127.0.0.1:8083; отдельная Strata и сеть ОС не ограничивались.

Данные скопированы из результатов реальных вызовов, не созданы как тестовые ответы. Секреты авторизации в отчёты не входят. Код ревью проверяет хеши без повторного inference.
