# Сценарий видео — День 17

Запуск: `node record-video.mjs`. Скрипт сам запускает локальное приложение, выполняет реальные запросы в UI и сохраняет `ChallengeVideos/day17-demo.mp4`.

1. Показать вопрос о состоянии Git и вызов `get_git_snapshot({"scope":"summary"})`.
2. Показать полученную через `tools/list` схему входного параметра.
3. Показать JSON-ответ MCP и ответ агента, содержащий ветку и число изменений.
4. Переключиться на вопрос о последнем коммите и повторить вызов с `latest_commit`.
5. Показать, что хеш и заголовок коммита из результата использованы в ответе.

Видео без озвучки, с русскими подписями. Изображение H.264, 1920×1080, звук AAC (тишина), faststart.
