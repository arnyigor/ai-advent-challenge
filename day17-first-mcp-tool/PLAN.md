# День 17 — план до разработки

## Контракт

- Продолжить день 16: Python, официальный MCP SDK 2.2.0, stdio и локальный веб-интерфейс.
- Собственный MCP-сервер оборачивает локальный Git через безопасные команды только для чтения.
- Инструмент `get_git_snapshot(scope: Literal["summary", "latest_commit"])` объявляет имя, описание и схему аргументов через SDK. Он возвращает данные о текущем репозитории в JSON.
- Агент получает каталог по MCP, выбирает инструмент для одного из двух запросов, вызывает `tools/call`, читает ответ и формирует ответ пользователю из полученных данных.
- Веб-приложение показывает вопрос, имя и аргументы вызова, сырой результат MCP и ответ агента. CLI запускает тот же агентный код.
- Git-корень берётся из расположения проекта или `DAY17_REPO_ROOT`; произвольный путь из веб-запроса не принимается.

## Последовательность

1. Реализовать MCP-сервер и проверить схему через настоящий `tools/list`.
2. Реализовать агентный MCP-клиент и проверить реальный `tools/call` на двух сценариях.
3. Подключить агент к локальному веб-интерфейсу в стиле дней 15–16.
4. Написать интеграционные проверки, README и сценарий видео.
5. Записать реальный интерфейс и проверить MP4 с контрольными кадрами.
