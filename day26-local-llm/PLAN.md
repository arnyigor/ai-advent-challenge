# День 26 — анализ и план

## Что должно быть доказано

Задание не про обучение модели, RAG или агента. Нужны работающий локальный инференс, доступ к нему из кода и минимум три запроса разной сложности. Strata запускает пользователь. Повторная установка другой LLM не нужна.

Разделяем три независимых доказательства:

1. **Процесс и модель на машине.** На видео показать Strata, загруженный файл/идентификатор модели, готовность сервера и, если доступны, память GPU/CPU и лог генерации. Надпись «Strata» в нашем отчёте сама по себе ничего не доказывает.
2. **Обращение через HTTP.** CLI показывает запросы, ответы и полное время; JSON фиксирует endpoint, запрошенную и возвращённую модель. Разрешены только literal loopback-адреса. Это ограничение клиента, а не доказательство отсутствия облачного прокси внутри сервера.
3. **Три завершённых ответа.** Сохранённые результаты относятся к конкретному прогону. Ошибка не заменяется заглушкой. Качество ответа оценивается отдельно от работоспособности API.

## Что взято из предыдущих дней

- День 01: Node без дополнительных зависимостей, OpenAI-совместимый chat endpoint. Его облачный fallback и mock здесь намеренно не используются.
- День 05: явный адрес локального сервера, наблюдаемые ответы и измерения. Не копируем специфические параметры chat template, пока Strata их поддержка не подтверждена.
- День 25: сценарий по доказательствам, настоящие кадры и явное обозначение сокращённого ожидания. Генерация MP4 из кадров — монтаж, а не запись работающего приложения.

## Архитектура и контракт

Один `demo.mjs`: переменные окружения → последовательные HTTP POST → терминал → JSON и автономный HTML. Нет веб-сервера, пакетов, CDN, ключей, общих изменений в других днях. Отчёт открывается как локальный файл и подходит для спокойного показа крупных ответов в видео.

Предварительный контракт: `LOCAL_LLM_URL` — полный API base URL (обычно заканчивается `/v1`); `LOCAL_LLM_MODEL` — фактический id модели. POST `${base}/chat/completions`, JSON `{model, messages, stream:false}`; ответ `choices[0].message.content`. **Совместимость Strata ещё нужно подтвердить.** Адрес, порт и id не угадываются. Если Strata использует другой контракт, адаптировать только `request()` после проверки документации/ответа сервера.

Лимит времени по умолчанию 180 секунд на запрос; на медленной машине меняется переменной окружения. Не задаём неподтверждённые параметры генерации. Полное время включает соединение и генерацию; это не TTFT и не скорость токенизации. Usage показывается только как возвращённое сервером поле. Код из ответа не запускается автоматически.

## Три уровня сложности

| Уровень | Проверяемое поведение | Ожидаемая проверка |
|---|---|---|
| Простой | Короткий факт и следование формату | «Париж» одним словом |
| Средний | Несколько арифметических шагов и условие скидки | 3 × 1200 × 0.85 + 300 = 3360 рублей |
| Сложный | Генерация функции с ограничениями и примерами | Сохранение порядка, неизменность входа, `[3,1,2]`, `[]`, корректная сложность |

Первые две автоматические проверки лишь частичные: наличие числа 3360 не доказывает правильность объяснения. Третий ответ требует ручной проверки; никаких надписей «код прошёл тесты» без исполнения. Завершение по лимиту (`finish_reason=length`) нужно отметить как обрезанный ответ, даже если HTTP успешен.

## Порядок выполнения

1. Подготовить независимый клиент, тесты ошибок и отчёт — можно без Strata.
2. Пользователь запускает Strata и сообщает base URL и id модели. Проверить доступный API, при несовместимости уточнить контракт.
3. Запустить клиент. Первый простой запрос — минимальная проверка подсистемы; при ошибке проверить endpoint и лог Strata, не усложнять приложение.
4. Получить все три ответа, просмотреть JSON/HTML, вручную проверить расчёт и код. При повторе сохраняется отдельная папка; не выбирать удачные ответы скрытно.
5. Записать процесс Strata, CLI и отчёт по `DEMO.md`. При необходимости сократить паузы с подписью.
6. Проверить видео воспроизведением: читаемость, все три запроса/ответа, доказательство локального запуска, отсутствие секретов. Только затем назвать задание выполненным.

## Критерий готовности и ограничения

Тестовый HTTP-сервер проверяет клиент, но не Strata. Успешный синтаксис не подтверждает API. HTML не заменяет видео. До реального запуска и записи итог «локальная LLM запущена и отвечает» не заявляется. Видео хранится в `ChallengeVideos/day26-demo.mp4`, не в Git. Публикация, commit и push в эту задачу не входят.
