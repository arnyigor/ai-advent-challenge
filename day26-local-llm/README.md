## Факт прогона (2026-10-05, Strata v0.1.39)

Endpoint `http://127.0.0.1:8083/v1`, модель `qwen3.8-flash-next-iq3_s` (статус `loaded`, контекст 204 800). GPU RTX 5070 Ti, 15,6/16 ГБ VRAM, эксперты 3 427 (6,6 ГБ) в VRAM.

| # | Запрос | Время | finish_reason | Проверка |
|---|---|---|---|---|
| 1 | Столица Франции, одним словом | 3 234 мс | stop | «Париж» — частичная проверка пройдена |
| 2 | Расчёт со скидкой и доставкой | 7 975 мс | stop | 3 360 ₽ — частичная проверка пройдена |
| 3 | Функция `uniqueStable` + примеры | 14 055 мс | stop | код просмотрен вручную; дополнительно исполнен отдельно: `[3,1,2]`, вход не изменён, `[] → []` |

Проверки — частичные: они подтверждают конкретные значения, но не оценивают качество модели в целом. Исполнение кода модели сделано вне стенда, вручную, как отдельная проверка.

Независимое подтверждение, что запросы обрабатывались локально: счётчик запросов в Strata Monitor вырос на 3 (111 → 114), и длительности в её журнале (3,2 / 8,0 / 14,1 с) совпали с временем клиента в пределах округления. В видео это сверяется на экране.

## Запуск

Нужен Node.js 22+ и запущенная Strata с OpenAI-совместимым API (в этом прогоне — подтверждено). Возьмите API base URL и id модели из Strata. Стенд не отключает защиту сервиса: если API требует ключ, сначала добавьте его поддержку в код, а не выключайте авторизацию.

Из корня репозитория, PowerShell:

```powershell
$env:LOCAL_LLM_URL = Read-Host 'API base URL (http://127.0.0.1:<порт>/v1)'
$env:LOCAL_LLM_MODEL = Read-Host 'ID загруженной модели'
node day26-local-llm/demo.mjs
```

CLI: три последовательных запроса без общей истории, затем `results/<timestamp>/report.html` + `report.json`. HTML автономный, внешних ресурсов нет; ответы выводятся текстом и не исполняются.

Веб-стенд (тот же источник запросов и проверок, что и CLI):

```powershell
$env:DAY26_WEB_PORT = '8788'
node day26-local-llm/server.mjs   # http://127.0.0.1:8788
```

Стенд слушает только loopback, проксирует запросы к Strata, показывает журнал HTTP, живой счётчик генерации и сохраняет отчёт именно своего прогона (кнопка-ссылка «Открыть сохранённый отчёт»).

Без конфигурации CLI завершается с понятным сообщением и кодом 1. Ошибка одного запроса не останавливает остальные: отчёт фиксирует ошибки, exit code 1. Код 0 означает три непустых HTTP-ответа, **не** доказанную правильность ответов или локальный инференс — смотрите `validation` и `finishReason`.

Ограничения клиента: разрешены только `http://127.0.0.1` и `http://[::1]` (`localhost` намеренно запрещён), редиректы не следуются, облако не подключается, таймаут по умолчанию 180 с (`LOCAL_LLM_TIMEOUT_MS`).

## Проверки

```powershell
node --check day26-local-llm/demo.mjs
node --check day26-local-llm/demo.test.mjs
node --test day26-local-llm/demo.test.mjs
node day26-local-llm/demo.mjs --help
```

Тесты (10) используют только временный loopback HTTP-сервер, не LLM: сериализация трёх запросов, непустой ответ, ошибки HTTP/JSON/формата, timeout, запрет редиректов и удалённых адресов, экранирование HTML, продолжение после ошибки. Реальная работа Strata подтверждена отдельным прогоном (см. выше) и видео.
