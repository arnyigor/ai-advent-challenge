Напиши JavaScript-функцию uniqueStable(values), которая убирает дубликаты, сохраняя порядок. Не изменяй входной массив. Покажи примеры для [3,1,3,2,1] и []. Кратко укажи временную сложность. Не используй внешние библиотеки.
ОТВЕТ
```javascript
function uniqueStable(values) {
  const seen = new Set();
  const result = [];

  for (const value of values) {
    if (!seen.has(value)) {
      seen.add(value);
      result.push(value);
    }
  }

  return result;
}
```

Примеры:

```javascript
console.log(uniqueStable([3, 1, 3, 2, 1])); // [3, 1, 2]
console.log(uniqueStable([])); // []
```

Временная сложность: `O(n)` в среднем, так как `Set.has()` и `Set.add()` выполняются примерно за `O(1)`.
