## Что проговорить про третий ответ

Модель прислала функцию `uniqueStable` с примерами для `[3,1,3,2,1]` и `[]`. На видео код не исполняется; подпись не заявляет тестов. Вне видео код был исполнен вручную как отдельная проверка: `[3,1,2]`, исходный массив не изменён, `[] → []`, порядок сохранён — сложность O(n) на Set корректна при обычном предположении о стоимости операций.
