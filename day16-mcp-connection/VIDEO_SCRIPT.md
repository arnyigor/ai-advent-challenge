# Сценарий видео — День 16

## Основная версия: UI предыдущих дней

1. Открыть интерфейс; объяснить выбор сервера, каталог и параметры.
2. Выбрать учебный сервер, нажать «Подключиться», получить 2 инструмента.
3. Показать add с обязательными a и b, затем greet с параметром name.
4. Выбрать Jarvis и подключиться; показать реальное число инструментов.
5. Найти list_directory, открыть карточку с описанием и параметрами.
6. Показать обязательный path и необязательные параметры, раскрыть JSON-схему.
7. Проверить поиск без совпадений, затем найти rag_search.
8. Показать журнал: запуск, успешный handshake, каталог, закрытие сессии.

Запись: `node record-ui.mjs`. Результат: `ChallengeVideos/day16-demo.mp4`.
1920×1080, H.264 Baseline/AAC, русские подписи, без озвучки.

## Предыдущая техническая версия

1. Показать последовательность initialize → tools/list → закрытие сессии.
2. Показать реальный фрагмент mcp_client.py с ClientSession.
3. Запустить CLI с командой существующего Jarvis MCP Server.
4. Показать фактический handshake, сервер, версию протокола и число инструментов.
5. Показать весь полученный список инструментов на нескольких экранах.
6. Показать JSON Schema list_directory: обязательный path, типы и значения по умолчанию.
7. Запустить интеграционные pytest-тесты и показать итог.

Русские подписи, без озвучки. Данные получаются заново при записи.
При отсутствии MCP_DEMO_COMMAND тот же сценарий использует локальный demo_server.py.
Результат: ChallengeVideos/day16-cli-demo.mp4; формат H.264/yuv420p, 1440×1000.
