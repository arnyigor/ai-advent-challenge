## Контракт

- Локальный дочерний MCP-сервер, транспорт stdio, официальный пакет mcp.
- Клиент выполняет initialize, затем tools/list и закрывает сессию.
- Два инструмента: add(a: int, b: int) -> int и greet(name: str) -> str.
- Сервер объявляет инструменты; клиент получает описания и inputSchema по MCP,
  а не импортирует серверный реестр. Вызов инструментов не входит в задание.
- CLI печатает результат соединения, сервер, версию протокола, число инструментов,
  имена, описания и JSON Schema. --json предоставляет машиночитаемый результат.
- Ошибка подключения даёт ненулевой код возврата; предусмотрен таймаут.
