# День 12. Персонализация ассистента

**Видео-демо:** [day12-demo.mp4 на Яндекс.Диске](https://yadi.sk/i/geX5wiogDTij4g) — одинаковый факт памяти и вопрос для Анны и Бориса, запуск двух ролей по профилю Анны и реальные ответы DeepSeek V4 Flash и DeepSeek Reasoner рядом.

Пользователь сервиса редактирует собственный профиль в веб-интерфейсе: обращение, стиль, формат, ограничения, фразу запуска и порядок ролей. Профили хранятся в `data/profiles.db` по `user_id`. Это отдельная настройка поверх трёх слоёв памяти дня 11; содержимое `data/` исключено из git.

**Отличие от дня 11:** память отвечает на вопрос «что агент знает?» — например, срок проекта. Профиль отвечает на вопрос «как агент должен работать для этого пользователя?» — как обратиться, в каком формате ответить и какие роли запустить. В демо Анна и Борис получают один факт (`срок = 15 декабря`) и задают один вопрос. Для Анны запускаются `analyst → developer`; Борис получает обычный ответ. Каждый вариант проходит через две реальные модели одного провайдера: DeepSeek V4 Flash и DeepSeek Reasoner.

## План реализации

1. Переиспользовать `MemoryStore` и сборку контекста дня 11 без копирования слоёв памяти.
2. Добавить хранилище профилей с проверкой схемы и изоляцией пользователей.
3. При каждом запросе автоматически добавлять профиль в системную инструкцию и показывать его в preview.
4. При совпадении фразы запроса запускать выбранные роли последовательно; результат предыдущих ролей передавать следующей.
5. Сравнить два профиля при одинаковом факте памяти и вопросе на двух реальных моделях; записать видео.

## Запуск

```powershell
cd day12-personalization
python web_server.py
```

Адрес и свободный порт выводятся в консоль. Режим «Офлайн-демо» работает без ключа для проверки интерфейса. Для записи видео нужны `DEEPSEEK_API_KEY` и доступ к моделям `deepseek-v4-flash` и `deepseek-reasoner`. В интерфейсе также доступны Gemini и Wormsoft через адаптеры дня 11. Качество соблюдения стиля реальной LLM зависит от модели.

## Проверка и видео

```powershell
python -m py_compile profile_store.py personalized_agent.py web_server.py
python -m pytest ../tests/test_day12_personalization.py ../tests/test_day11_memory_layers.py -q
node --check web/app.js
node --check record-video.mjs
python run_evaluation.py      # живое сравнение двух моделей, расходует API-токены
node record-video.mjs         # живое видео V4 Flash + Reasoner
```

Скрипт записывает локальное видео `ChallengeVideos/day12-demo.mp4`: одинаковый факт памяти, профиль Анны и две роли, профиль Бориса без ролей, реальные ответы обеих моделей рядом. MP4 не попадает в git. Запись проверяет структуру контекста перед сохранением. Живые ответы и структурные проверки сохраняются в `results/evaluation-two-models.json`.

Локальный веб-сервер предназначен для демо на `127.0.0.1`; `user_id` здесь выбран самим посетителем. При переносе в сервис его нужно получать из авторизованной сессии, а не из поля формы.
