# Сценарий видео

1. Показать формулу RAG: вопрос → vector search → top-4 → контекст → LLM.
2. Выбрать вопрос об аварийном коде Atlas и запустить два режима.
3. Сравнить ответ без базы и точный ответ с RAG.
4. Показать четыре реально найденных чанка, score и source.
5. Прокрутить контрольный набор из 10 вопросов с ожиданиями и источниками.
6. Завершить агрегированными метриками сохранённого отчёта.
