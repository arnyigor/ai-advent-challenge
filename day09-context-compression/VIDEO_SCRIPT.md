# Сценарий видео Day 9

Ролик записывается командой:

```bash
node record-video.mjs
```

Продолжительность — около 50 секунд, итоговая частота — 24 fps. Титры находятся
сверху под шапкой и не перекрывают composer/слайдер внизу. Диалог наполняется
по ходам прямо в кадре, а не подставляется готовым. `record-video.mjs` поднимает
настоящий web UI, читает `results/comparison.json`, записанный после реального
A/B-прогона, делает кадры через headless Chrome и собирает MP4 через ffmpeg.

Сцены:

1. Пустой чат: пока история короткая, модель получает её целиком.
2. Ходы 1–4: четыре факта (Маяк-17, Казань, 480 000, PDF) с нейтральным фоном.
3. Ходы 5–8: нейтральный фон, «Полная история» и «Контекст LLM» растут вместе.
4. Момент сжатия: 10 старых сообщений → сводка, «Контекст LLM» падает 2593 → 1270.
5. Четыре проверочных вопроса: ответы восстановлены из сводки.
6. Фактический расход сессии по реальному прогону.
7. A/B-таблица: одинаковые диалоги и модель, качество 100% в обоих режимах.
8. Итоговая экономия: 3 395 входных токенов (11,7%).
9. Файлы с основной реализацией.

Числа не подставляются заранее: ролик читает сохранённый результат фактического
прогона. Для обновления видео сначала повторно запустите `run_comparison.py`.

Что именно показано на панели:

* «Полная история» / «Контекст LLM» — локальные оценки токенов, поэтому «≈»
  (тот же формат, что и в живом UI). До сжатия обе плитки показывают
  `request_tokens_estimate` соответствующего хода реального прогона: пока
  сводки нет, история и есть запрос.
* «Фактический расход сессии» — накопительная сумма реальных `usage` из
  `results/comparison.json`, включая отдельный вызов суммаризатора (2 508
  токенов). В конце ролика значения обязаны совпасть с итогами прогона —
  `record-video.mjs` проверяет это и падает при расхождении.
* Все реплики — дословные: рекордер читает transcript сессии `day09-compressed`
  из `comparison.db`. Сообщения setup-ходов по ~1 400 символов (факт плюс
  нейтральный блок на 180 слов) — именно поэтому расход доходит до 25 654
  входных токенов. В кадре такой пузырь обрезан по высоте, но под ним
  показана настоящая длина сообщения.
