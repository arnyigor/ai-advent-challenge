# Стек-профиль: JS / Node.js (без TypeScript)

## Известные ловушки

- **`this` в стрелочной функции — свойстве объекта.** `свойство: async (...) => { ... this ... }`
  не привязывает `this` к объекту-владельцу (в ESM top-level `this` — `undefined`).
  Всегда: `async methodName(...) { ... this ... }`.
  (Реальный случай: `cli.mjs` падал на первом запуске без явного `--backend`.)
- **Потерянный `await` в цепочке промисов** — `array.forEach(async x => ...)` не ждёт завершения
  колбэков, ошибки внутри тихо проглатываются. Использовать `for...of` + `await` или
  `Promise.all(array.map(...))`, если нужен параллелизм.
- **Необработанный reject в фоновой задаче** (`someAsyncFn()` без `.catch`/`await`/`try-catch`) —
  в Node это не всегда роняет процесс, ошибка может просто исчезнуть.

## Проверка синтаксиса

```
node --check path/to/file.mjs
```
(для `.js`/`.cjs` — аналогично)
