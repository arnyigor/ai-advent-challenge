# День 25 — реализованный план

1. CLI и веб используют один ChatAgent с реальным RAG дня 24: vector + FTS5, порог 0.83, до 16 кандидатов каждого канала, 8 выбранных фрагментов, проверка цитат и смысла.
2. История используется для самостоятельного поискового запроса; исходный вопрос и память отдельно передаются в генерацию. Поисковые синонимы не считаются фактами.
3. Цель фиксируется кодом после первого успешного обновления. Уточнения, ограничения и термины дополняются программным merge. Для смены цели или отмены ограничения создаётся новая сессия.
4. История, состояние и события записываются атомарной SQLite ATTACH-транзакцией. Ошибка модели памяти сохраняет старое состояние и проверенный ответ.
5. UI всегда показывает блок источников; при отказе явно пишет, что доказательства не найдены. Пользователь может открыть дословную цитату и восстановить сессию.
6. Два сценария по 12 сообщений проверяют источники, цитаты, цель на каждом ходу, передачу памяти, сохранность ограничений и терминов. Неудачные контрольные прогоны сохранены отдельно.
7. Офлайн-тесты включают сбой провайдера, откат частичной записи, передачу памяти и восстановление.
8. Демо с восемью поясняющими этапами; монтаж настоящих кадров интерфейса с сокращением ожидания ответов; финальный кадр — отчёт сценариев.
