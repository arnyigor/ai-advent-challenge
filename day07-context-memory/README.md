# Day 7: Сохранение контекста

**Видео-демо:** [day07-demo.mp4 на Яндекс.Диске](https://yadi.sk/i/J9LQaMpeGMOpdw)

Форк [`day06-first-agent`](../day06-first-agent) — тот же `ChatAgent`/`AgentStore`/
web-чат/CLI, плюс персистентная история диалога, переживающая перезапуск
процесса.

## Что добавлено поверх Day 6

- `history_store.py` — `SQLiteHistoryStore`: хранит сообщения (`session_id`,
  `role`, `content`) в одном файле `chat_history.db` (stdlib `sqlite3`, без
  новых зависимостей).
- `agent.py` — `ChatAgent` принимает `history_store` и `session_id`;
  подгружает историю при создании, дописывает после каждого успешного
  `ask()`, чистит при `reset()`.
- `web_server.py` — общий `SQLiteHistoryStore` на все веб-сессии, новый
  `GET /api/history?session_id=...` для восстановления чата в браузере.
- `web/app.js` — `session_id` хранится в `localStorage` (переживает
  перезагрузку страницы), при загрузке страницы подтягивает и рендерит
  сохранённую историю.
- `day07_agent.py` — CLI, флаг `--session <имя>` (по умолчанию `cli`);
  печатает, сколько реплик восстановлено из файла при старте.

## Проверка на практике

CLI (сессия `"cli"` фиксирована по умолчанию — рестарт процесса продолжает
тот же диалог):

```bash
python day07_agent.py "Запомни: мой любимый цвет — фиолетовый."
python day07_agent.py "Какой мой любимый цвет?"   # новый процесс — агент помнит
```

Web: `python web_server.py`, открыть `http://127.0.0.1:8007/`, пообщаться,
перезапустить `web_server.py` и обновить страницу — история подтянется через
`GET /api/history`, а следующий вопрос учитывает прошлый контекст.

`chat_history.db` не коммитится (см. `.gitignore`).

## Видео

Скрипт-рекордер сам поднимает `web_server.py`, пишет факт в чат, **убивает
процесс сервера целиком** (`server.kill()`, не `/api/reset`), поднимает его
заново, перезагружает страницу и продолжает диалог вопросом, ответ на
который знает только уже мёртвый процесс — так видно, что помнит именно
файл на диске, а не оперативная память.

Пересъёмка (headless Chrome CDP + ffmpeg, без npm-зависимостей):

```bash
node record-video.mjs
```
