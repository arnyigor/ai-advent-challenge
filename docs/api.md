# API помощника разработчика, день 31

## CLI

`python day31-developer-assistant/assistant.py --index` создаёт или обновляет индекс.
`python day31-developer-assistant/assistant.py --inspect` показывает его метаданные
и список источников без загрузки модели. Позиционный аргумент — команда
`/help <вопрос>`. Без аргумента показывается справка запуска; модель не вызывается.
`--retrieve-only` выполняет настоящий MCP и поиск без генерации.

## HTTP

`server.py` слушает 127.0.0.1; порт выбирается через `DAY31_WEB_PORT` (дефолт 8796).
`GET /api/config` возвращает статистику индекса и имя настроенной модели.
`POST /api/help` принимает JSON `{"command":"/help Как устроен проект?"}`.

Результат содержит `question`, `answer`, `project`, `mcp`, `sources`, `model`,
`usage`, `finish_reason`, `citation_ids_valid`, `has_citations`, `retrieval_sec`,
`generation_sec`. `project` — живой Git-контекст. `mcp` содержит имя сервера,
протокольную версию, список инструментов, arguments и результат вызова.
`sources` — найденные фрагменты с путём, заголовком секции, текстом и rank.
Поле `prompt` удаляется из HTTP-ответа; найденные документы видны отдельно.

Ошибки: 400 — неверная команда или JSON, 409 — запрос уже выполняется или индекс
устарел, 413 — тело больше 8192 байт, 502 — сбой MCP/retrieval/локального API.
Запрос ограничен 1000 символами вопроса. Запросы принимаются только с ожидаемым
Host и Origin. Ответы вставляются в DOM через textContent, внешних CDN нет.

## MCP

Сервер `day31-project`, transport stdio. Инструмент `get_project_context()` без
аргументов возвращает `repository`, `branch`, `head`, `detached`.
branch равен текущей ветке Git; detached HEAD обозначается `(detached HEAD)`.
head — полный SHA из `git rev-parse HEAD`. Корень проекта задаётся серверу через
`DAY31_REPO_ROOT`; клиент передаёт корень того же проекта, который индексирует.
Вызовы не содержат пользовательских shell-команд.

## Настройки модели

Локальная LLM не обязательна. DAY31_LLM_PROVIDER выбирает local, gemini или
openrouter. DAY31_LLM_MODEL — alias облачной модели. Gemini использует существующий
клиент tools/llm и GEMINI_API_KEY из окружения. OpenRouter использует
OPENROUTER_API_KEY, только openrouter/free или :free модели, без платного fallback.
В облако передаются вопрос, найденные фрагменты и Git-контекст. При 429/API ошибке
HTTP возвращает явную ошибку; скрытого перехода к другому провайдеру нет.
Сам retrieval и MCP не зависят от выбранного генератора ответа.

`LOCAL_LLM_URL` — явный loopback HTTP URL, включая `/v1`.
`LOCAL_LLM_MODEL` — имя модели. `LOCAL_LLM_MAX_TOKENS` — бюджет ответа,
по умолчанию 4096, допустимо 128–8192 (реализация дня 28).
`LOCAL_LLM_API_KEY` — необязательный ключ; его не включать в корпус и видео.
Модель не стартует автоматически вместе с UI. Отдельный запуск собственного
llama-server допускается с настройками пользователя; чужие процессы не останавливать.
